# 素材图规格说明

真实 AI 试穿（阿里云百炼 `outfit-any-one`）需要**真实照片**作为输入：模特人物图 + 服装商品图。请按下表放入对应目录，文件名固定（代码按名引用，`js/data.js` 中 `photo` / `topImage` / `bottomImage` 字段）。

## 模特人物图 → `assets/models/`

| 文件 | 对应形象 | 要点 |
| --- | --- | --- |
| `m1.jpg` | 小雨 · 青年/纤细 | 正面全身站姿 |
| `m2.jpg` | 安然 · 轻熟/标准 | 双臂自然下垂 |
| `m3.jpg` | 曼曼 · 青年/大码 | 表情自然或无脸均可 |

**拍摄要求**（直接影响试穿效果）：

- 正面、全身、直立，双脚完整入镜
- 背景简洁纯色（白墙最佳），光线均匀
- 穿**贴身打底**（修身 T 恤 + 紧身裤），宽松衣物会导致换装错位
- 三张构图尽量一致（相同机位距离、人物占画面比例相近）
- 建议尺寸：竖构图，短边 ≥ 768px；JPG 格式

## 服装商品图 → `assets/garments/`

| 文件 | 服装 | 类型 |
| --- | --- | --- |
| `c1_top.jpg` | 焦糖色长风衣 | 上装 |
| `c2_top.jpg` + `c2_bottom.jpg` | 米白麻花针织衫 + 炭灰直筒裤 | 上装 + 下装 |
| `c3_top.jpg` | 墨绿收腰连衣裙 | 连身（只放 top） |
| `c4_top.jpg` + `c4_bottom.jpg` | 雾霾蓝宽松衬衫 + 燕麦阔腿裤 | 上装 + 下装 |
| `c5_top.jpg` | 驼色羊绒大衣 | 上装 |
| `c6_top.jpg` | 格纹呢料连衣裙 | 连身（只放 top） |

**拍摄要求**：

- 平铺（flat-lay）或挂拍，服装完整、无模特穿着
- 纯色背景（白/浅灰），与服装颜色区分明显
- 正面朝上、无复杂褶皱遮挡版型
- 短边 ≥ 768px；JPG 格式

## 放好之后

1. 启动后端后访问 `http://localhost:8177/api/health`，`assetsReady` 应为 `true`
2. 大屏端生成模式自动从 Mock 切换为真实 AI（前端启动时探测）
3. 未放素材/未配 Key 时自动回退 Mock 演示模式，不影响现有流程
