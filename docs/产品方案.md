# 「衣然 YIRAN」AI 虚拟试衣镜 · 产品方案

## 一、目标用户与场景

| 用户群 | 动机 | 设计应对 |
|---|---|---|
| 逛街路过的年轻客群（核心） | 好玩、晒圈、顺手领优惠 | 3 步出结果、效果可扫码带走 |
| 同行陪同者 | 帮朋友试、社交互动 | 换形象/换款一步直达，全程免输入 |
| 门店周边价格敏感新客 | 占便宜、比价 | ¥30 新客券前置露出，到店即用 |

**场景约束**：站立操作、单人 1–2 分钟、身后可能有人等——一切设计为"零输入、大按钮、可随时无痕退出"。

## 二、核心流程（大屏 3 步 + 手机 2 步）

```
大屏（拉新体验装置）                    手机（承接转化）
吸引页(轻触开始)                        扫码 → 试穿结果落地页
 → ① 选形象：3 款体型/气质各异           → 商品详情 + 按形象推荐尺码
 → ② 挑服装：6 款即点即上身              → 领 ¥30 新客券
 → ③ AI 生成：约 5 秒分步反馈            → 预约到店试穿（主）/ 加购（次）
 → 结果大图 + 二维码                     → 分享有礼
```

**转化漏斗**：生成完成数 → 扫码率 → 结果页浏览率 → 领券率 → 到店试穿率 → 转化率。原型内已埋演示级事件日志（控制台可见）。

**新客判定**（正式版）：试穿全程零输入零登录，新客资格不在体验环节判定；仅在领券环节（顾客主动获益时）以手机号验证码绑定会员体系判新——新客发 ¥30 券、老客转等值复购礼。采集时点选在获益处而非体验处，符合《个保法》最小必要原则；原型演示省略验证步骤。

## 三、大屏与手机端分工

- **大屏 = 体验装置**：重体验、轻信息、零输入。只做"穿上身"的 Wow 时刻，不放价格锚点与复杂决策，缩短单人占用时间、降低排队流失。
- **手机 = 转化与留存**：重信息、重交易。承接商品详情、尺码推荐、优惠、预约与分享；扫码参数只含商品编号，无后端、不落库。

## 四、异常处理

| 异常 | 方案 |
|---|---|
| 生成等待 | 分步文案（分析版型→贴合身形→渲染光影）+ 进度条 + 轮廓动效，管理时间预期 |
| 生成失败 | 情绪友好文案 + 一键重试（重试必成功）+ "换一件"降级出口，绝不死胡同 |
| 长时间无操作 | 45 秒触发提示 → 10 秒倒计时 → 回吸引页并清除本次会话 |
| 参数异常（手机端） | 兜底展示演示组合并明示，不白屏 |

## 五、隐私保护（按《个人信息保护法》最小必要原则）

1. **预设形象优先**：不强制拍照即可完整体验，儿童/老人零风险；
2. **拍照增强路径**（正式版）：二次授权弹窗明示三条承诺——仅本机处理、试后即删、不作他用；未授权不可进入；
3. **不落库**：纯前端方案，二维码参数只含商品编号，不含任何个人信息；手机页关闭即清除；
4. **退出即清**：闲置超时/换人使用自动清除会话；
5. **店内告知**：吸引页常驻"不采集摄像头、不留存影像"声明。

## 六、迭代方向

试衣记录合集（一次扫多款）、会员码打通（扫码即识别会员等级）、A/B 测试扫码动文案、排队叫号模式、导购端工作台（预约提醒 + 备货尺码）。
