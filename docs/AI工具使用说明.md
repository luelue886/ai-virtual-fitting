# AI 工具使用说明

## 一、使用的工具

| 工具 | 用途 |
|---|---|
| Claude Code（桌面版，Anthropic） | 全程主力：需求拆解讨论、产品方案共创、原型代码生成与调试 |
| 计划模式（Plan Mode） | 与 AI 对齐 6 项关键设计决策后再动手，避免返工 |
| 浏览器实测工具 | 对原型做全流程点击测试、像素级视觉校验、控制台排错 |

## 二、关键提示词

### 1. 原始任务（笔试题原文）

> 背景：某服装品牌计划在商场门店设置一块 AI 虚拟试衣大屏。顾客可选择人物形象和服装款式，生成试衣效果，并扫码将结果带到手机端。
> 任务：请设计一个简化版虚拟试衣原型，重点考虑操作门槛、生成等待与失败、隐私保护，以及从试穿到了解或购买商品的转化路径。

### 2. 角色设定

> 你是一名高级产品经理。熟悉产品从 0-1 设计，具备复杂需求拆解、产品方案设计、用户转化链路、漏斗分析模型、UI 原型设计。
> task：1、制定完整的项目实施计划，要求面面俱到；2、核心功能设计需要与我讨论完成。

### 3. 核心功能讨论（AI 提出选项、本人逐项决策）

- **形象来源**：AI 给出"预设为主+可选拍照 / 仅预设 / 拍照为主"三案 → 本人选定**预设为主+可选拍照**（同时回应门槛与隐私两个考点）；
- **AI 生成实现**：选定**前端模拟+可切换架构**（演示稳定，且预留真实 API 切换点，体现工程化思考）；
- **交付形式**：选定**GitHub Pages 公网部署**，二维码=链接+商品参数，无后端不落库；
- **转化路径**：选定**全漏斗·到店优先**（人已在商场，最优转化是即时到店，线上加购为次路径）；
- **视觉风格**：选定**时尚简约·暖调**（米白+暖橙，亲和不冷场，呼应低门槛）。

### 4. 关键实现指令（节选）

> 纯静态站、零构建、vanilla HTML/CSS/JS，生成器抽象为独立模块（MockGenerator / APIGenerator），文档说明如何切换真实 API。
> 二维码参数只含商品编号，不含任何个人信息——这本身是隐私设计的亮点。
> 45s 闲置 → 倒计时 → 回吸引页并清除会话（本身即隐私动作）。

## 四、AI 与本人的分工边界

- **AI 完成**：项目实施计划初稿、原型全部代码、两份文档初稿、浏览器自动化测试；
- **本人完成**：6 项关键设计决策、产品方案审阅定稿、上述"主要修改"、最终演示与答辩。
